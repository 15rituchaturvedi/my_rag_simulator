What each path does

📘 IndexingPrepare source content before anyone asks a question. Split it and store searchable representations.
🔎 RetrievalEmbed the question and compare it with indexed chunks to find relevant context.
💬 GenerationGive the retrieved text to an LLM, which produces an answer based on that context.

Simulation note: This educational demo uses local hashed word vectors and cosine similarity, not neural embeddings. Its final response is extractive (it selects source sentences), not generated by a real LLM. It does not fetch URLs or parse PDFs. The visual styling is inspired by the clean blue-and-white hospitality aesthetic; it is not affiliated with Choice Hotels.
